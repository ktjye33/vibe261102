# PRD: DemoPort — 개발자 프로필 웹사이트

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 개인 프로필·포트폴리오 웹사이트 |
| 연락처 | ktjye33@gmail.com |
| 주력 분야 | Python, HTML5, iOS 앱 개발 |
| 문서 버전 | v0.1 (2026-11-03) |

DemoPort는 개발자의 기술 스택, 프로젝트, 경력을 한곳에 보여주고 채용 담당자·클라이언트·협업자가 쉽게 연락할 수 있도록 하는 단일 페이지 중심의 개인 웹사이트입니다.

## 2. 목표

### 2.1 비즈니스 목표
- 개발자 개인 브랜드 구축 및 온라인 이력서 역할
- 채용·외주·협업 문의 유입 창구 확보
- Python / HTML5 / iOS 세 분야의 전문성을 명확히 전달

### 2.2 성공 지표
- 첫 화면 로딩 2초 이내 (Lighthouse Performance 90점 이상)
- Lighthouse Accessibility / SEO 90점 이상
- 방문자가 3클릭 이내에 연락처에 도달
- 모바일·데스크톱 모두에서 레이아웃 깨짐 없음

## 3. 대상 사용자

| 사용자 | 기대 사항 |
|---|---|
| 채용 담당자 / 리크루터 | 기술 스택, 경력, 이력서를 빠르게 확인 |
| 외주 클라이언트 | 완성된 프로젝트 사례와 연락 방법 |
| 동료 개발자 | GitHub 링크, 코드 샘플, 기술 블로그 |

## 4. 핵심 기능 (요구사항)

### 4.1 Hero (첫 화면) — 필수
- 이름 / 한 줄 소개 (예: "Python · Web · iOS Developer")
- 주력 분야 3가지 배지: **Python**, **HTML5**, **iOS**
- CTA 버튼: "프로젝트 보기", "연락하기"

### 4.2 About (소개) — 필수
- 프로필 사진, 간단한 자기소개 (3~5문장)
- 개발 철학 / 관심 분야

### 4.3 Skills (기술 스택) — 필수
분야별 카드로 구분해 표시합니다.

| 분야 | 예시 기술 |
|---|---|
| Python | Python 3, FastAPI / Django / Flask, 데이터 처리(pandas), 자동화 스크립트 |
| HTML5 / Web | HTML5, CSS3, JavaScript, 반응형 웹, 웹 접근성 |
| iOS | Swift, SwiftUI, UIKit, Xcode, App Store 배포 |
| 공통 도구 | Git, GitHub, REST API 설계 |

- 각 기술에 숙련도(예: 주력 / 능숙 / 사용 경험) 표시

### 4.4 Projects (포트폴리오) — 필수
- 프로젝트 카드: 썸네일, 제목, 요약, 사용 기술 태그, 링크(GitHub / 데모 / App Store)
- 분야 필터: 전체 / Python / Web / iOS
- 카드 클릭 시 상세 보기(모달 또는 상세 페이지): 문제, 역할, 해결 방법, 결과

### 4.5 Experience (경력 · 학력) — 필수
- 타임라인 형식: 기간, 소속, 역할, 주요 성과

### 4.6 Contact (연락처) — 필수
- 이메일: **ktjye33@gmail.com** (`mailto:` 링크 + 복사 버튼)
- GitHub, LinkedIn 등 소셜 링크
- (선택) 간단한 문의 폼 — 외부 폼 서비스 연동

### 4.7 부가 기능 — 선택
- 다크 모드 / 라이트 모드 전환
- 한국어 / 영어 전환
- 이력서 PDF 다운로드
- 기술 블로그 / 글 목록

## 5. 비기능 요구사항

- **반응형**: 모바일(360px~) / 태블릿 / 데스크톱 대응
- **성능**: 이미지 최적화(WebP, lazy loading), 외부 라이브러리 최소화
- **접근성**: 시맨틱 HTML5 태그, 대체 텍스트, 키보드 탐색, 충분한 명도 대비
- **SEO**: meta 태그, Open Graph, 사이트맵
- **브라우저 지원**: Chrome, Safari(iOS 포함), Edge, Firefox 최신 버전
- **유지보수**: 프로젝트·경력 데이터는 별도 데이터 파일(JSON 등)로 분리해 코드 수정 없이 갱신

## 6. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 마크업 | HTML5 (시맨틱 태그) | 주력 분야 강조, SEO·접근성 |
| 스타일 | CSS3 (CSS 변수, Flex/Grid) | 의존성 없이 가볍게 |
| 스크립트 | Vanilla JavaScript | 필터, 다크 모드, 모달 |
| 데이터 | `data/projects.json` 등 | 콘텐츠 분리 |
| 빌드/도구 (선택) | Python 스크립트로 정적 페이지 생성 | Python 역량 활용 |
| 배포 | GitHub Pages / Netlify / Vercel | 무료 정적 호스팅 |
